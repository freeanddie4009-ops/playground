2026 Lara AI 플레이그라운드 — 웹호스팅 설치 안내
=============================================

1. 파일질라(FileZilla)로 아래 파일·폴더를 전부 호스팅(html 폴더)에 업로드합니다.
   index.html / api.php / config.php / seed.json / .htaccess
   uploads/ / storage/ / story_banners/

2. 사이트 주소를 열고 [교사 로그인]에서 비밀번호 2026 을 입력하면
   바로 관리실에 들어갑니다. (설치키·최초 설정 없음)

3. 관리실에서 링크·HTML·ZIP 웹앱·수업자료·썸네일을 등록하고 [공개]로 저장하면
   모든 학생에게 똑같이 보입니다.

* 비밀번호를 바꾸려면 config.php의 'admin_password' 값을 수정해 다시 업로드하세요.
* 업로드 파일은 uploads/ 폴더에, 목록은 storage/content.json에 저장됩니다.
* HTML 파일을 더블클릭해 단독으로 열 때도 같은 비밀번호 2026 으로 로그인합니다.
  (단독 모드 등록 내용은 그 브라우저에만 저장됩니다.)
