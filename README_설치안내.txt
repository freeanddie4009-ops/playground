2026 Lara AI 플레이그라운드 — 독립형 홈페이지
=======================================

[중요] 이 패키지는 기존 freeanddie.dothome.co.kr 사이트와 데이터·계정·파일을 연결하지 않습니다.
외부 교육용 앱의 원래 제작사 링크는 그대로 사용할 수 있습니다.
기존 홈페이지 서버에만 저장돼 있던 HTML 웹앱 2개와 수업자료 3개의 실제 파일은
새 사이트에 포함돼 있지 않습니다. 관리실에 최초 파일 업로드가 필요합니다.

A. HTML 파일 하나로 사용하기 (간편 테스트 / 단독 환경)
-------------------------------------------------
- index.html 파일을 더블클릭하여 브라우저에서 엽니다.
- 메인 이미지, 영역별 페이지, 앱 검색/즐겨찾기, 교사 관리 화면이 작동합니다.
- 교사 로그인 > 처음 관리실 설정하기에서 비밀번호를 만듭니다.
- 외부 링크 등록, 단일 HTML 앱 등록, PDF·문서·동영상 수업자료 등록이 가능합니다.
- 등록 내용은 현재 브라우저의 localStorage/IndexedDB에만 저장됩니다.
- 다른 기기/학생에게 자동 공유되지 않습니다. 시크릿 모드/브라우저 데이터 삭제 시 사라질 수 있습니다.
- 교사 관리 화면에서 백업 JSON을 내보내고 다시 가져올 수 있습니다.
- 이 모드에서 ZIP 프로젝트를 브라우저에서 실행하는 기능은 제공되지 않습니다.

B. 웹호스팅에 배포하고 학생들에게 똑같은 콘텐츠 제공하기 (권장)
-------------------------------------------------
- PHP 7.4 이상과 파일 쓰기 권한이 있는 호스팅(예: PHP 지원 웹호스팅)에 업로드합니다.
- 이 압축 파일의 '배포용' 폴더에 있는 다음을 함께 업로드합니다:
  index.html / api.php / config.php / seed.json / .htaccess / uploads/ / storage/
  (INSTALL_KEY_설치키.txt 는 서버에 올리지 마세요.)
- 업로드 후 새 사이트 URL을 엽니다. api.php가 연결되면 관리실에 '서버 공유 모드'로 나타납니다.
- 교사 로그인 > 최초 설정에서 INSTALL_KEY_설치키.txt의 설치키를 입력하고
  새 교사 비밀번호(8자 이상)를 정합니다.
- 교사 관리실에서 링크/HTML/ZIP 웹앱/수업자료/썸네일을 등록하고 [공개]로 저장합니다.
- 공개한 앱과 수업자료는 다른 브라우저와 학생에게도 공통으로 표시됩니다.
- 관리실에서 [임시저장]으로 변경하면 학생에게 보이지 않습니다.
- 서버에 업로드되는 파일은 uploads 폴더에, 목록 정보는 storage/content.json에 저장됩니다.

업로드 가능:
- 외부 링크: https://... URL
- 단일 HTML 웹앱: .html / .htm
- HTML 프로젝트 ZIP: index.html과 JS/CSS/그림 등이 포함된 ZIP(서버 ZipArchive 필요)
- 수업자료: PDF, HWP/HWPX, Word, PPT, Excel, 이미지, 영상, 음성, ZIP, 텍스트 등
- 썸네일: JPG, PNG, WebP, GIF

[보안 / 주의]
- 학생의 개인정보나 민감한 파일은 공개 등록하지 마세요.
- HTML 앱은 안전을 위해 업로드 경로에서 브라우저 샌드박스로 격리합니다.
  마이크·카메라·특수 권한이 필요한 HTML 앱은 다른 독립 도메인으로 배포한 뒤
  외부 링크로 등록하는 편이 안정적입니다.
- 서버 PHP 업로드 크기 제한(upload_max_filesize, post_max_size)이 더 작을 수 있습니다.
- 각종 글꼴과 추가 라이브러리는 패키지에 의존하지 않습니다.
- 사이트 배포 전 HTTPS 연결을 권장합니다.
- 백업 시 storage 폴더 + uploads 폴더를 함께 복사하세요.
- HTML 파일만 정적 호스팅하면 서버 공동 저장은 구현되지 않습니다.

포함 초기 콘텐츠:
- Reading / Art / Sport / 라라 RAS 영역과 기존 사이트에서 공개된
  외부 교육 앱 링크 10개가 기본 등록돼 있습니다.
- 기존 서버에만 존재하던 HTML 앱 2개와 수업자료 3개는 '임시저장' 상태입니다.
  각 항목을 [수정]해 원본 파일을 업로드한 뒤 [공개]로 전환하세요.

교사 비밀번호를 잊었을 때:
- 서버 관리자만 storage/admin.json을 안전하게 별도 백업·삭제한 뒤 최초 설정을 다시
  진행할 수 있습니다. 반드시 기존 관리자의 허락을 받고 수행하세요.
- 단독 HTML 모드는 현재 브라우저에만 설정이 저장됩니다.

[이번 업데이트: 버튼 효과 · 바로 열기 · 썸네일]
- 웹앱 카드의 버튼은 마우스 클릭 시 별빛이 짧게 반짝입니다.
- 외부 웹앱 주소는 일반 링크로 새 탭을 열며, 홈페이지 자체의 확인창은 없습니다.
  단, 외부 사이트나 브라우저/플랫폼이 띄우는 보안 경고는 이 HTML에서 제거할 수 없습니다.
- 교사 관리실에서 썸네일 PNG/JPG/WebP/GIF(5MB 이하)를 올리면 즉시
  앱 카드, 상세 페이지, 수업자료 목록, 관리자 목록에 함께 표시됩니다.
- '수정'으로 기존 이미지 교체, '현재 썸네일 제거' 체크로 삭제할 수 있습니다.
- 업데이트 배포 시 index.html과 api.php를 교체하되 기존 storage/ 와 uploads/
  폴더는 절대로 덮어쓰거나 삭제하지 마세요. 등록된 자료와 이미지가 그곳에 있습니다.
- 이 버전은 기존 등록 자료의 데이터 형식과 호환됩니다.

[스토리 배너 최종 디자인]
- 메인 홈페이지 첫 화면은 기존의 전체화면 그림을 유지합니다.
- Reading / Art / Sport / 라라 RAS 내부 페이지 상단 배너를
  4개 개별 스토리형 통합 이미지로 교체했습니다.
- 하단 앱 카드 3열 템플릿/태그 필터/검색/즐겨찾기/수업자료는 그대로 유지됩니다.
- 교사 등록 썸네일은 카드·상세·교사 관리 목록에서 동일하게 표시됩니다.
- 이야기 배너 이미지는 index.html에 포함되어 있으며 추가 story_banners 폴더는
  별도 수정 또는 백업용입니다. index.html 실행에는 별도 이미지 파일이 필요 없습니다.
- 외부 웹앱은 홈페이지의 별도 확인창 없이 일반 링크로 새 탭에서 엽니다.
  (브라우저 자체의 확인창까지 강제로 없앨 수는 없습니다.)
- HTML 단독 파일에서는 등록 내용이 그 브라우저에만 저장되며, 학생과 공유하려면
  이 배포 패키지를 PHP 7.4+ 지원 웹서버에 설치해야 합니다.
- 기존 서버 업데이트 시 storage/ 및 uploads/ 파일을 보존해야 등록 자료가 유지됩니다.
