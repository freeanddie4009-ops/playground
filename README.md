# 2026 Lara AI 플레이그라운드 (Vercel 배포판)

배곧라라초 학생용 교육 웹앱 모음 홈페이지입니다.
선생님이 교사 페이지에서 등록하면 모든 사람이 바로 볼 수 있습니다.

| 하는 일 | 쓰는 것 |
|---|---|
| 홈페이지 화면 | `index.html`, `assets/` |
| 교사 로그인, 저장, 업로드 | `api/` (Vercel 서버 함수) |
| 게시물 목록 저장 | Upstash Redis (무료) |
| 썸네일, 수업자료, HTML 웹앱 파일 저장 | Vercel Blob (무료) |

---

## 처음 배포하기 (한 번만)

### 1. GitHub에 올리기
1. GitHub에서 새 저장소를 만듭니다. 예: `playground`
2. 압축을 푼 폴더 **안의 파일 전체**를 저장소에 올립니다.
   (`index.html`, `api`, `lib`, `assets`, `package.json`, `vercel.json` 등이 저장소 맨 위에 있어야 합니다.)

### 2. Vercel 프로젝트 만들기
1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인합니다.
2. **Add New → Project**에서 방금 만든 저장소를 **Import**합니다.
3. Framework Preset은 **Other**로 두고 **Deploy**를 누릅니다.

### 3. 파일 저장소(Vercel Blob) 연결
1. 프로젝트 화면 위쪽의 **Storage** 탭 → **Create Database** → **Blob**을 고릅니다.
2. 접근 방식(Access)은 **Public**으로 만듭니다.
3. 이 프로젝트에 **Connect**합니다. (`BLOB_READ_WRITE_TOKEN`이 자동으로 들어갑니다.)

### 4. 데이터 저장소(Upstash Redis) 연결
1. **Storage** 탭 → **Create Database** → Marketplace의 **Upstash → Redis**를 고릅니다.
2. 무료(Free) 요금제로 만들고, 이 프로젝트에 **Connect**합니다.
   (`KV_REST_API_URL`, `KV_REST_API_TOKEN`이 자동으로 들어갑니다.)

### 5. 교사 비밀번호 정하기
1. **Settings → Environment Variables**로 갑니다.
2. 이름은 `TEACHER_PASSWORD`, 값은 `2026`으로 넣고 저장합니다.
3. (선택) `SESSION_SECRET`에 아무 긴 글자를 넣으면 로그인 보안이 더 단단해집니다.

> 비밀번호는 코드에 적지 않고 Vercel 설정에만 둡니다. GitHub 저장소가 공개여도 비밀번호는 보이지 않습니다.

### 6. 다시 배포하기
설정을 바꾼 뒤에는 **Deployments → 맨 위 배포의 ⋯ → Redeploy**를 한 번 눌러야 적용됩니다.

### 7. 확인
1. 배포된 주소(예: `https://playground-xxxx.vercel.app`)를 엽니다.
2. 오른쪽 위 **교사 로그인**에서 `2026`을 입력합니다.
3. 연결이 빠진 것이 있으면 노란 상자에 무엇이 빠졌는지 나옵니다.

## 사용하기

- **웹앱 등록:** 교사 로그인 → 웹앱 관리 → 새 웹앱 등록
  - 웹앱 형태 **링크 주소**: 누르면 새 탭으로 열립니다.
  - 웹앱 형태 **HTML 파일**: 홈페이지 안 실행 화면에서 열립니다(돌아가기, 전체 화면 버튼).
- **수업자료:** 수업자료 관리에서 웹앱을 고르고 파일(여러 개 가능, 한 파일 50MB 이하) 또는 링크를 올립니다.
- **공지사항:** 공지사항 관리에서 씁니다. "중요"로 표시하면 맨 위에 고정됩니다.
- **숨기기:** 웹앱 관리 표의 "사용중/숨김"을 누르면 학생 화면에서 잠시 숨길 수 있습니다.
- **삭제:** 휴지통을 두 번 누르면 지워집니다. 웹앱을 지우면 연결된 수업자료와 파일도 함께 정리됩니다.

## 알아 두기

- **동시에 고치면:** 두 곳에서 동시에 고치면 나중에 저장한 쪽에 "다른 곳에서 먼저 바뀌었어요" 안내가 나오고 최신 내용을 다시 불러옵니다. 내용이 덮어써지지 않습니다.
- **비밀번호 보호:** 비밀번호를 10번 틀리면 10분 동안 로그인이 막힙니다.
- **HTML 웹앱의 제약:** 학생 안전을 위해 HTML 웹앱은 격리된 화면에서 실행됩니다.
  - 웹앱 안의 기록 저장은 창을 닫으면 지워집니다.
  - 마이크·카메라를 쓰는 웹앱은 링크로 등록하는 것이 가장 확실합니다.
- **무료 사용량:** 학교 홈페이지 정도의 사용량이면 Vercel·Upstash 무료 범위 안에서 충분합니다. 한도는 각 서비스 대시보드에서 확인할 수 있습니다.

## 폴더 구성

```
index.html            홈페이지 화면 전체
assets/               배경, 버튼, 로고, 배너, 아이콘 그림
assets/vendor/        파일 업로드 도구 (@vercel/blob 2.9.0 묶음)
api/me.js             로그인 상태와 연결 상태 확인
api/login.js          교사 로그인 (비밀번호 확인, 틀린 횟수 제한)
api/logout.js         로그아웃
api/data.js           게시물 목록 읽기
api/save.js           게시물 목록 저장 (교사만, 판 번호로 충돌 방지)
api/upload.js         파일 업로드 허가 (교사만, 50MB 이하)
api/delete-files.js   쓰지 않는 파일 정리 (교사만)
lib/common.js         공통 기능 (세션, 저장소, 입력값 검사)
```
